Acme Docs

ai-support-widget — Demo

This is a stand-in for "your docs site." Click the chat bubble in the bottom-right corner. It's powered by qlaud, with each visitor getting their own per-end-user spending cap so the bot can't be abused into running up your bill.

Getting Started

Pretend this section talks about installing Acme. Try asking the widget: “How do I install Acme?” 

npm install acme

Configuration

Acme reads its config from acme.config.js. The widget knows about this — try asking it “Where do I set the API key?”

How the widget got here

The host page only adds one line:

<script
  src="/widget.iife.js"
  data-server="https://your-worker.workers.dev"
  data-title="Acme Support"
  data-greeting="Hi! I'm the Acme bot. Ask me anything."
  data-accent="#dc2626"
  defer></script>
Note: in this dev setup, the widget points at http://localhost:8787 (the worker run via wrangler dev). In production you'd replace it with your deployed worker URL.
