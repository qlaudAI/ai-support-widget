ai-support-widget

Drop streaming chat onto any site.

One <script> tag, ~5KB gzipped, Shadow-DOM isolated. Powered by qlaud with a hard per-visitor spending cap so anonymous traffic can’t blow up your bill.

Click the chat bubble in the bottom-right corner to try it.

Getting started

Pretend this section talks about installing Acme. Try asking the widget: “How do I install Acme?” 

npm install acme

Configuration

Acme reads its config from acme.config.js. The widget knows about this — try asking it “Where do I set the API key?”

How the widget got here

The host page only adds one line:

<script
  src="/widget.iife.js"
  data-server="https://your-worker.workers.dev/chat"
  data-title="Acme Support"
  data-greeting="Hi! I'm the Acme bot. Ask me anything."
  data-accent="#dc2626"
  defer></script>
Note: in this dev setup, the widget points at http://localhost:8787/chat (the worker run via wrangler dev). In production replace it with your deployed worker URL.
